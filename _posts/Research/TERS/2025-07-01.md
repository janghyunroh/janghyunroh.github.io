---

 이번에 화학과 연구실과 함께 소프트웨어 개발 과제를 진행하게 되었다. TERS라는 실험 장비에 대한 개발을 수행하는 과제인데, 아무래도 중학교 시절부터 화학과는 담을 쌓고 지냈다보니 프로젝트 진행을 위한 배경 지식이 한참 부족함을 느끼기 시작했다.

 TERS는 **Tip-Enhanced Raman Spectroscopy(팁 강화 라만 분광법)**의 약자로, 이름에서 알 수 있듯 라만 분광법(Raman Spectroscopy)을 기반으로 한다. 따라서 TERS를 이해하기 위해서는 먼저 라만 분광학의 원리를 이해해야 한다.

---

## 1. 빛과 물질의 상호작용

 물질에 빛(광자, photon)을 쪼이면 세 가지 현상이 발생할 수 있다.

- **흡수(Absorption)**: 광자가 전자를 들뜬 상태로 전이시키며 에너지를 흡수한다.
- **투과(Transmission)**: 빛이 물질을 그냥 통과한다.
- **산란(Scattering)**: 빛이 물질에 부딪혀 다른 방향으로 재방출된다.

 분광학(Spectroscopy)은 이 중 산란 또는 흡수된 빛의 **에너지(파장)를 분석**하여 물질의 구조 및 성질을 파악하는 학문이다.

---

## 2. 라만 산란(Raman Scattering)

### 탄성 산란 vs 비탄성 산란

 빛이 물질에 산란될 때, 에너지 변화 여부에 따라 두 종류로 나뉜다.

| 산란 종류                            | 에너지 변화   | 현상                              |
| ------------------------------------ | ------------- | --------------------------------- |
| **레일리 산란(Rayleigh Scattering)** | 없음 (탄성)   | 입사광과 동일한 파장으로 재방출   |
| **라만 산란(Raman Scattering)**      | 있음 (비탄성) | 입사광과 **다른** 파장으로 재방출 |

 대부분의 산란은 레일리 산란이다. 라만 산란은 전체 산란 중 약 $10^{-7}$ 수준의 극히 미미한 비율로 발생한다.

### 라만 산란의 원리

 입사 광자가 분자와 충돌하면, 분자를 **가상 에너지 상태(virtual energy state)**로 들뜨게 한다. 이후 분자가 다시 낮은 에너지 상태로 돌아올 때:

- 원래 **진동 기저 상태(ground state)**로 돌아오면 → 입사광과 같은 에너지로 재방출 = **레일리 산란**
- 원래보다 **높은 진동 상태**로 돌아오면 → 에너지를 잃고 더 긴 파장으로 재방출 = **스토크스 라만 산란(Stokes Raman)**
- 원래보다 **낮은 진동 상태**로 돌아오면 → 에너지를 얻고 더 짧은 파장으로 재방출 = **안티-스토크스 라만 산란(Anti-Stokes Raman)**

$$
\tilde{\nu}_{Raman} = \tilde{\nu}_{laser} \pm \tilde{\nu}_{vibration}
$$

여기서 $\tilde{\nu}$는 파수(wavenumber, $\text{cm}^{-1}$)를 나타내며, $+$는 Anti-Stokes, $-$는 Stokes 산란에 해당한다.

---

## 3. 라만 스펙트럼과 분자 지문

 라만 산란에서 에너지 변화량 $\Delta\tilde{\nu}$는 **라만 이동(Raman shift)**이라 부르며, 이 값은 분자의 **진동 모드 에너지**에 직접 대응한다. 즉, 어떤 분자가 어떤 주파수로 진동하는지가 라만 스펙트럼에 고스란히 담긴다.

 서로 다른 분자들은 화학 결합의 종류, 길이, 각도에 따라 고유한 진동 모드를 가지므로, 라만 스펙트럼은 **분자 지문(Molecular Fingerprint)** 이라고도 불린다.

```
   강도
(Intensity)
    |
    |     스토크스 산란         레일리 산란    안티-스토크스 산란
    |         |                    |                |
    |    _____|_____          _____|_____       _____|_____
    |   |           |        |           |     |           |
    +---+-----------+--------+-----------+-----+-----------+--→ 라만 이동 (Raman Shift, cm⁻¹)
      음수 방향  ←  0  →  양수 방향
```

 스토크스 산란이 안티-스토크스 산란보다 강도가 높아(상온에서 기저 상태 분자가 더 많으므로) 실제 분석에서는 주로 **스토크스 라만 스펙트럼**을 사용한다.

---

## 4. 일반 라만 분광기의 구성

 라만 분광기는 크게 네 부분으로 구성된다.

```
  [레이저 광원]
       |
       ↓
  [빔 스플리터/필터]  ← 레일리 산란 제거용 노치(Notch)/엣지(Edge) 필터
       |
       ↓
  [시료 (Sample)]  ← 여기서 라만 산란 발생
       |
       ↓
  [분광기 (Spectrometer)]  ← 회절격자(Diffraction Grating)로 파장 분리
       |
       ↓
  [검출기 (CCD Detector)]  ← 파장별 강도를 전기 신호로 변환
```

1. **레이저 광원**: 단색광(monochromatic light)을 제공. 파장이 정확해야 라만 이동을 정확히 계산할 수 있다.
2. **노치/엣지 필터**: 강도가 압도적으로 센 레일리 산란을 제거하여 미약한 라만 신호만 남긴다.
3. **분광기**: 회절격자를 이용하여 산란광을 파장별로 분리한다.
4. **CCD 검출기**: 파장별 빛의 강도를 전기 신호로 변환하여 스펙트럼을 기록한다.

## 5. 라만 분광법의 한계와 TERS의 등장

 일반적인 라만 분광법은 강력한 분석 도구이지만, 한 가지 치명적인 한계가 있다.

> **공간 분해능(Spatial Resolution)이 빛의 회절 한계(Diffraction Limit)에 묶여 있다.**

 빛의 회절 한계는 아베 한계(Abbe Diffraction Limit)라고도 하며, 다음과 같이 표현된다:

$$
d_{min} \approx \frac{\lambda}{2 \cdot NA}
$$

여기서 $\lambda$는 레이저 파장, $NA$는 대물렌즈의 개구수(Numerical Aperture)이다. 가시광선 영역 레이저($\lambda \approx 500\text{ nm}$)를 사용할 경우, 분해능의 한계는 아무리 좋아도 **수백 나노미터 수준**에 불과하다.

 하지만 나노미터 수준의 국소 영역에 대한 분자 정보가 필요한 경우, 일반 라만 분광으로는 역부족이다.

 이 문제를 해결하기 위해 **TERS(Tip-Enhanced Raman Spectroscopy)** 가 등장한다. TERS는 원자력 현미경(AFM) 또는 주사 터널링 현미경(STM)의 금속 탐침(Tip)을 레이저 초점 근처에 위치시켜, 탐침 끝의 **플라즈몬 공명(Plasmon Resonance)**을 통해 국소 전자기장을 수십 나노미터 크기로 극도로 집중시킨다. 이를 통해 일반 라만의 회절 한계를 넘어 **나노미터 수준의 공간 분해능**으로 라만 신호를 측정할 수 있게 된다.

## 6. 정리

| 특성        | 일반 라만 분광       | TERS                                          |
| ----------- | -------------------- | --------------------------------------------- |
| 공간 분해능 | ~수백 nm (회절 한계) | ~수십 nm 이하                                 |
| 신호 증폭   | 없음                 | 플라즈몬 공명으로 $10^6 \sim 10^{10}$ 배 증강 |
| 장치 복잡도 | 낮음                 | 높음 (AFM/STM + 라만 통합)                    |
| 주요 응용   | 화학 성분 분석       | 나노 스케일 표면/소재 분석                    |
